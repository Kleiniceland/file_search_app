## 二、技术栈替换汇总

| # | 原计划 | 实际使用 | 替换原因 | 影响范围 |
|---|--------|----------|----------|----------|
| 1 | TensorFlow Lite | ONNX Runtime | tflite_flutter Windows DLL 加载失败 | 所有模型需重新导出为 ONNX 格式 |
| 2 | Chroma DB | ObjectBox HNSW | Chroma 无 Flutter 桌面原生绑定 | 向量存储层全部重写 |
| 3 | PDFium + Tika | syncfusion_flutter_pdf | Flutter 原生 Dart 库，无需 JVM | PDF 解析实现简化 |
| 4 | BERT-base 768 维 | BERT 轻量 512 维 | 内存限制（650→360 MB）+ 语义区分度差 | 嵌入引擎内存减半 |
| 5 | BERT CLS 向量 | Mean Pooling | CLS 向量不相关文本相似度 >0.93 | 嵌入准确性大幅提升 |
| 6 | Hive 暴力扫描 | ObjectBox HNSW | O(n) 性能不达标 | 检索性能从 O(n) 提升至 O(log n) |
| 7 | Google Test | flutter_test + integration_test | Flutter 桌面端原生测试框架 | 测试体系 |

| # | 限制 | 原因 |
