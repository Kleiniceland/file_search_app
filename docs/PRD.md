# 产品需求文档 (PRD)

## 1. 项目使命

整理全球信息，使其普遍可访问且有用。解决数十亿用户（包括视障人士）难以在个人设备上高效搜索和检索非结构化本地内容的痛点。

## 2. 目标用户

- 需要管理大量本地文档（PDF/Word/TXT）的知识工作者
- 需要通过自然语言查找截图/图片的视觉用户
- 依赖屏幕阅读器的视障用户
- 关注数据隐私、要求完全离线的用户

## 4. 非功能性需求

| ID | 需求 | 指标 |
|----|------|------|
| NF1 | 离线运行 | 全部推理在本地进程内，无网络请求 |
| NF2 | 搜索延迟 | < 500ms (1000 文件库) |
| NF3 | 内存占用 | < 500 MB (三模型全部加载) |
| NF4 | 索引吞吐 | ≥ 5 文件/秒 (TXT) |
| NF5 | 向量检索复杂度 | O(log n) via HNSW |
| NF6 | 模型推理 | flutter_onnxruntime 进程内推理，禁止 Python sidecar |

## 5. 约束

- 所有嵌入向量必须 L2 归一化为单位长度
- FileReaderFactory.getReader 是获取文件读取器的唯一入口
- 文本提取必须通过 compute() 卸载到 isolate
- 嵌入向量维度统一为 512（文本和图像）
- 搜索结果评分：关键词匹配时 0.4×语义 + 0.6×关键词；无关键词时 0.3×语义 (≥0.15)
